# 🏥 Hospital Appointment Booking System

## 📌 Overview
A robust, console-based Java application designed to streamline patient management and appointment scheduling.
This project serves as a backend demonstration of object-oriented programming, secure database connectivity, and dynamic SQL integration.

## 💻 Tech Stack
* **Language:** Core Java
* **Database:** MySQL
* **Connectivity:** JDBC (MySQL Connector)

## ✨ Key Features
* **Interactive CLI:** User-friendly command-line interface for system navigation.
* **Database Integration:** Dynamic data retrieval and management using SQL queries.
* **Security Focused:** Scrubbed database credentials to protect sensitive information in version control.
